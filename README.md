# Landing page starter

Responsive Vite starter for standalone landing pages.

## Run locally

Install Node.js LTS, run `npm install`, then `npm run dev`. Run `npm run build` to create the production site.

## New projects

Create a GitHub repository from this starter and import it into Vercel. Vercel can then create preview deployments for pull requests and production deployments from the configured branch. Each new site needs a one-time GitHub-to-Vercel project link.

Edit `index.html` for page content and metadata, `src/style.css` for design, and `src/main.js` for interactions. Keep secrets in local `.env.local` and Vercel project settings; never commit them.
